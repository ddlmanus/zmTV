# 造梦 API 平台接入

zmTV 面向用户只提供一个生成服务：[造梦 API 开放平台](https://api.zaomeng.art)。应用固定使用 `https://api.zaomeng.art`，不需要选择供应商或填写 Base URL。

## 获取和配置令牌

1. 打开 [造梦 API 开放平台](https://api.zaomeng.art)，注册或登录账户。
2. 进入平台控制台的“令牌管理”。
3. 创建令牌并复制。平台中的“令牌”对应 zmTV 设置页中的“API 密钥”。
4. 打开 zmTV 的“设置”页面，将令牌粘贴到“API 密钥”输入框并保存。
5. 等待连接验证和模型目录加载完成。

模型目录、生成请求、文件上传、异步任务轮询、账户余额和生成历史均使用这个平台账户。令牌属于敏感凭据，不要提交到 Git、写入源码、发布到 Issue，或出现在公开截图和日志中。

## 应用调用范围

| 能力     | 平台职责                                           |
| -------- | -------------------------------------------------- |
| 模型目录 | 返回账户可用模型、endpoint、输入 schema 和价格信息 |
| 媒体上传 | 将本地文件转为供应商可访问的公网 URL               |
| 内容生成 | 提交图片、视频、音频、3D 和数字人任务              |
| 任务轮询 | 查询异步任务状态并归一化成功或失败结果             |
| 账户信息 | 返回美元余额、计费记录和生成历史                   |

工作流中的模式来自当前模型的 endpoints，参数来自当前 endpoint schema。模型版本和 endpoint 不应按相似名称合并，前端价格按平台返回的美元计价展示。

## 请求生命周期

```text
本地素材
  -> api.zaomeng.art 上传
  -> 获得公网 URL
  -> 提交生成任务
  -> 保存 taskId / predictionId
  -> 轮询任务状态
  -> 归一化图片、视频、音频、3D 或数字人结果
  -> 回填工作流节点和生成历史
```

页面切换或应用恢复后，任务应通过已保存的任务关联继续轮询，不能只依赖组件内的 Promise。

## 主要代码位置

| 位置                                 | 职责                                       |
| ------------------------------------ | ------------------------------------------ |
| `src/api/client.ts`                  | 平台认证、模型、余额、历史与统一任务客户端 |
| `src/api/platformMedia.ts`           | 平台媒体模型目录、上传和任务调用           |
| `src/stores/apiServiceStore.ts`      | 固定平台地址与旧服务配置迁移               |
| `src/stores/apiKeyStore.ts`          | 令牌验证和安全存储                         |
| `src/workflow/ideart/lib/wavespeed/` | 工作流模型路由、schema 与请求构建          |
| `src/workflow/backend/client.ts`     | 渲染进程到桌面工作流后端的桥接             |
| `electron/workflow-backend/`         | 本地路由、任务轮询、Codex 与持久化         |

代码中保留的其他供应商适配器属于内部兼容实现，不会在设置页面向用户开放，也不能改变默认平台地址。

## 常见问题

### 设置页不能修改 Base URL

这是预期行为。zmTV 统一使用 `https://api.zaomeng.art`，用户只需填写平台令牌。

### 令牌验证失败

回到平台控制台确认令牌未被禁用、删除或过期，并确认复制时没有多余空格。不要使用其他 One API、New API 或 WaveSpeed 服务的密钥代替造梦平台令牌。

### 模型列表为空

确认令牌验证成功且当前账户拥有模型权限，然后重启应用或刷新模型目录。若问题仍存在，请保留不含令牌的错误信息用于排查。
