# 原生全品类组图合同

## 代码真相源

本 Skill 不维护独立的商品组图提示词副本。嵌入式运行时直接使用：

- `backend/lib/studio-genesis.ts`：数量、画幅、分辨率、语言和任务类型合同。
- `backend/lib/studio-genesis-ai.ts`：商品理解、复杂结构判断、质量修复、主图背景差异、详情页规划与逐图提示词。
- `backend/app/api/studio-genesis/*`：原商品模块的鉴权、积分预检、任务、轮询、历史和持久化链路。

原模块未来修改上述规则时，Skill 运行时必须通过函数复用继承更新，不能复制旧提示词形成分叉。

## 模式映射

| 用户意图 | imageType | 默认说明 |
|---|---|---|
| 商品主图、主图套图、白底主图 | `main` | 逐图独立背景；平台白底 MAIN 例外 |
| 商品详情页、详情页组图、详情图、PDP | `detail` | 一屏一个卖点；真实背景与参考锁定依据 |

## 参数合同

- 参考商品图：1–6 张。
- 规划张数：1–15 张。
- 画幅：`1:1`、`4:5`、`3:4`、`9:16`、`16:9`。
- 分辨率：`1K`、`2K`、`4K`。
- 默认值由 `DEFAULT_STUDIO_GENESIS_SETTINGS` 决定，不在 Skill 内另写一套。
- 模型由 `listStudioGenesisModels` 按当前商户和后台场景配置选择。

## 商品身份与复杂结构

复杂结构为折叠、伸缩、旋转、多独立零件物理约束，或螺纹、卡扣、铰链、导轨、齿轮等精密结构。复杂商品只能从参考图实际存在的角度规划；所有商品都禁止改造本体或臆造不可见功能。

## 主图背景差异验收

创意主图之间至少变化 3 个背景属性：场景、台面材质、空间层次、道具、光向、机位、前景、墙地结构、景深。以下均判失败：同背景换颜色、同渐变换色、同展台移动、同道具换位置、产品只缩放。

## 详情页验收

每屏必须有不同页面角色、一个真实卖点、参考图可见依据、禁止变形边界、构图和信息层级。无依据的数字、成分、认证、评价、价格和效果不得出现。

## 媒体边界

所有实际图片通过造梦平台模型和计费链路生成。Codex 不直连供应商，不把计划或排队状态当作完成。独立场景底图必须是无人物、无角色、无动物、无身体局部和无人物影子的干净空场。
